# Портфолио Антона Усанова

Статический сайт на Astro 7, без адаптера и без Tailwind. Скоупленные
`<style>` в каждом компоненте, токены — обычные CSS-переменные в
`src/styles/tokens.css`. Деплой на GitHub Pages, домен antnusnv.com.

## Что ломается чаще всего

**Скоупленные стили Astro не доходят внутрь дочернего компонента.**
`<Icon class="status-icon" />` + `.status-icon { width: 32px }` в родителе
не сработает: хэш скоупа на элемент внутри `Icon.astro` не попадает. Из-за
этого иконки гипотез долго рендерились 20px вместо 32. Размер и цвет
вложенного компонента задаём **пропом** (`<Icon size={32} />`), а не CSS
снаружи. Исключение — `:global()` от селектора, который принадлежит
родительскому шаблону: `.close :global(path) { fill: … }` работает.

**Любая правка русского текста обязана идти в паре с `src/i18n/en.ts`.**
Переводы ищутся по точному отрендеренному тексту элемента
(`EN[ru.trim()]` в `src/scripts/scramble.ts`), отдельных ключей нет.
Лишняя точка, «2 раунд» → «2-й раунд» — и элемент молча остаётся русским.
После правки текста запускать `npm run typograph:i18n`; сборка сама
падает, если ключ разошёлся с разметкой.

**Типографику ставит `src/middleware.js`, а не шаблоны.** Typograf гоняется
и в dev, и при пререндере — одинаковый текст в обоих режимах критичен,
потому что он же служит ключом перевода. В шаблонах текст пишем обычными
пробелами и прямыми кавычками.

## Изображения

`astro.config.mjs` заставляет sharp кодировать webp **без потерь**: любое
lossy-сжатие разваливает градиенты на скриншотах интерфейсов в
прямоугольные блоки, и повышение quality не спасает (замерено: q90 → q100
ошибка не падает, lossless → 0).

Множитель для ретины — **3×**. Потолки ширины: `ImageBlock` 3504 в рамке
и 3600 без, `Gallery` — тройная высота с ограничением по исходнику.

Часть подписей **впечена в сами PNG** (скетч аналитиков, прототип на
price-audit, первый экран галереи публикации в каталогах). Такой текст не
переводится на английский — это известное ограничение, не баг.

## Раскладка

- `< 576px` — мобильная, отдельное дерево компонентов в `components/mobile/`
- `576–1199.98px` — планшет, макет 1200px, боковой отступ 113px ужимается пропорционально
- `≥ 1200px` — десктоп

`.page-container` ниже 1200px получает `overflow-x: clip`, а он, в отличие
от `hidden`, обрезает и `position: fixed`-потомков. Оверлеи монтируем через
слот `overlay` в `Shell.astro` — вне контейнера.

## Сверка с Figma

Сравнивать **геометрию** — отступы, ширины колонок, размеры кадров. Точки
переноса строк не сравнивать: Figma рендерит настоящий SF Pro и не переносит
по дефисам, плюс у текстовых слоёв бывает зафиксирована высота. Разница в
количестве строк сама по себе не баг вёрстки.

Метаданные крупных страниц не влезают в ответ MCP (обрыв на ~13k символов).
Обходной путь: `get_screenshot` всей страницы на полном разрешении, потом
резать на полосы и читать; `get_design_context` отдаёт полный код и
переживает лимит через файл.

## Проверка

`npx astro check` + `npm run build`, дальше чтение DOM через браузерную
панель (`getBoundingClientRect`, `getComputedStyle`, `naturalWidth`).
**Скриншоты в этом окружении приходят пустыми** — на них не полагаться.
Скрембл-анимация переключения языка успокаивается за 15–40 секунд, замеры
делать после.

Проверка переводов: переключить на EN, обойти листья
`[data-i18n], [data-i18n-scope]` и отфильтровать оставшуюся кириллицу.
